# Frozen model weights

The public `v1.0.0` repository and DOI archive do not include model weights. This is the explicit release scope recorded in `config/release_policy_v1.0.0.json`.

The manifest in `config/frozen_ensemble_v1.0.0.json` records the 15 controlled checkpoint paths and SHA-256 values for provenance. Do not substitute retrained, renamed or approximate checkpoints, and do not copy controlled weights into the public repository.
