# Data access and privacy boundary

This repository is for source code, frozen configuration, model artefacts approved for release, and synthetic examples.

It must not contain:

- participant-level RBPT or SAT images;
- names, dates, sample numbers, medical-record numbers, hospital or centre names, or source-path metadata;
- real truth labels, patient-level predictions, ensemble-member predictions, error-audit rows, or bootstrap replicate rows;
- private ZIP archives, browser or application profiles, credentials, tokens, or local absolute paths.

The synthetic example images and prediction rows are artificial and cannot be used to infer study-participant information. Access to controlled clinical evidence is governed separately by the study's ethics, consent, institutional and data-access arrangements; this code repository does not create a right of access to those records.
